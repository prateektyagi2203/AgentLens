# Test-operator keys (public TEST key, synthetic)

`test-operator.private.pem` is a **deliberately public TEST private key**. It is committed on purpose and protects nothing.

- It signs HTTP requests as the fictional operator `https://agents.desithreads.test` so that the synthetic traffic generator
  and the replay agent (`--sign`) can produce valid Web Bot Auth signatures (RFC 9421) for the demo store.
- The matching public key is in `test-operator-jwks.json`. The store serves it at
  `/.well-known/http-message-signatures-directory`, and AgentLens ships it in `services/api/identify/bundled_keys.json`.
- Anyone can sign as this operator. A "Verified" result for `agents.desithreads.test` therefore only proves that the
  verification code works, never that a real vendor's agent visited. Real vendors' keys are fetched from their own
  key directories.
- Never reuse this key, or a key generated by `pnpm --filter @agentlens/store gen-test-key`, for anything real.

No other private keys or secrets are committed. `.env` is gitignored; `.env.example` holds placeholders only.
