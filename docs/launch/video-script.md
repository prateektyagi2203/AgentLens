# 60-90 second demo video: shot list

Goal: one clear idea, "AI agents are a quarter of your traffic, they fail at specific places, and AgentLens tells you
where and what it costs." Record against the live site (<https://agentlens.ptlabs.in>) or `./tasks.ps1 preview-demo`.
Numbers come from the synthetic demo dataset (12,000 sessions); re-check them if you regenerate the data.

## Setup checklist

- 1080p, browser zoom 125%, one theme (dark looks best), private window, notifications off.
- Dashboard date filter on the full range 1-14 Nov; Story mode on.
- Have these tabs ready: Overview, Funnel (preset **Before fix**), Blockers -> B06 detail, Before / After.
- Burn in captions (many people watch muted). Export 16:9 for LinkedIn (or 1:1 if you prefer a bigger feed tile).
- Say once that the data is synthetic (the badge shows it).

## Tips

- Keep the cursor slow and deliberate; zoom into the number you are talking about.
- Cut dead time (loading spinners). The live API answers in well under a second, so there should be little.
- Upload the video natively to LinkedIn (not a YouTube link): native video gets more reach. Put the link in the first comment.
