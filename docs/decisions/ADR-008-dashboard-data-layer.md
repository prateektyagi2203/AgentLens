# ADR-005: Dashboard data layer (typed contract, mocks, demo snapshots)

Status: accepted (M4)

## Context
The dashboard (ADR-003: Next.js App Router + Tailwind + Recharts + TanStack Table) must be built and demoed before the
FastAPI backend exists, and must still be demo-able later without the backend (README, video, hosted static site).

## Decision
1. **One contract, two mirrors.** `docs/api-contract.md` is the normative HTTP contract; `apps/dashboard/lib/types.ts` mirrors every
   response 1:1 (snake_case, rupees as numbers). The backend agent implements the doc; the dashboard never reshapes API data.
2. **Three data modes, one module.** `lib/data-source.ts` resolves `MODE` once: `demo` (`NEXT_PUBLIC_DEMO_MODE=1`/`DEMO_MODE=1`)
   > `mocks` (`NEXT_PUBLIC_USE_MOCKS=1`) > `api`. `lib/api.ts` exposes typed functions only and dispatches on `MODE`.
   There is **no silent fallback** to mocks when the API is unreachable: the UI shows an error state with instructions.
3. **Fixtures are a reference backend.** `lib/fixtures/*` implement the contract (including settings validation, run polling,
   mark-as-fixed creating an annotation) behind `mockRequest(method, path, query, body)`; mock state lives in `sessionStorage`.
   Fixtures tell the hero story (pincode wall B05 ≈31% of failed agent sessions, ≈₹12.6 L/month; fix on 12 Nov lifts agent conversion ≈3.5% → ≈7.5%) and are unit-tested.
   The mock module is dynamically imported, so it is not in the bundle for `api`/`demo` builds' critical path.
4. **Static demo snapshots.** `public/demo/*.json` (layout in the contract, §4) is generated by `pnpm generate:demo` from the mock
   backend today and by `agentlens export-snapshot` from the real backend later. Demo builds use `output: "export"`.
   Filters are applied client-side only where cheap (sessions list, overview time series); the UI says so ("demo data").
5. **Detail views use query params** (`/blockers?id=B05`, `/sessions?id=…`, `/replays?id=…`) instead of dynamic route segments, so
   the static export works without `generateStaticParams` and links stay shareable. Global filters also live in the URL.
6. **Theme in one file.** All colours/fonts are CSS variables in `app/globals.css` (Tailwind v4 `@theme inline`, light + `[data-theme="dark"]`);
   components use semantic utilities only (`bg-card`, `text-muted-foreground`, `text-primary`, …). Agents = `--agent` (primary blue), humans = `--human` (slate), in both themes.

## Consequences
* Backend and frontend can be developed in parallel; contract drift is caught by `types.ts` + the fixture tests.
* Two implementations of the impact maths exist (fixtures and backend); the contract requires `risk_breakdown` to multiply out to `risk_inr.base`.
* The demo snapshot is static: interactive filters beyond sessions/overview time series are not recomputed in demo mode.
